# 🏫 Present, Please. (ระบบตรวจสอบการเข้าเรียนอัจฉริยะ)

> **แอปพลิเคชันมือถือสำหรับเช็กชื่อเข้าเรียนด้วย 3 ปัจจัยหลัก: เวลาเรียนจริง (Time) + พิกัด GPS และแผนที่จริง (Location & Real Map) + ภาพถ่ายยืนยันตัวตน (Photo Evidence)**  
> พัฒนาด้วย **React Native**, **Expo SDK 57**, **Expo Router**, **TypeScript**, และ **OpenStreetMap / Leaflet**

## ✨ จุดเด่นและฟีเจอร์หลัก (Features)

1. **🎨 ธีมและดีไซน์เอกสารทางการ (Bureaucratic Checkpoint Design)**
   - โทนสีกระดาษเอกสารและหมึกย้อนยุค สไตล์ตรวจบัตรรับรอง (Document / Stamp Theme)
   - ป้ายประทับสถานะชัดเจน: ผ่าน (เขียว), ไม่ผ่าน/ขาด (แดง), สาย (ส้ม), ทางการ (น้ำเงิน)
   - รองรับภาษาไทยทั้งระบบ คำศัพท์เป็นทางการและเข้าใจง่าย

2. **⏰ ระบบตรวจสอบเวลาเรียนอัตโนมัติ (Time-Window Locking)**
   - ล็อกไม่ให้นักศึกษาเช็กชื่อล่วงหน้าก่อนถึงเวลาเริ่มเรียน
   - ปิดรับการเช็กชื่อทันทีเมื่อหมดเวลาเรียนตามที่อาจารย์กำหนด
   - แจ้งเตือนสถานะเวลาแบบเรียลไทม์ พร้อมระบุกฎเกณฑ์ชัดเจน

3. **🗺️ แผนที่จริงแบบอินเทอร์แอคทีฟ (Interactive Real Map with OpenStreetMap)**
   - แสดงหมุดห้องเรียน `🏫` พร้อมวงรัศมีที่อนุญาตให้นักศึกษาเช็กชื่อ (เช่น 50 เมตร)
   - แสดงหมุดตำแหน่งปัจจุบันของนักศึกษา `👤` พร้อมวงความแม่นยำ GPS (Accuracy Circle)
   - เปลี่ยนสีจุดสถานะทันที: สีเขียว (อยู่ในรัศมี) / สีแดง (อยู่นอกรัศมี)
   - ลากเส้นประเชื่อมโยงระยะทาง (Distance Polyline) ระหว่างนักศึกษาและห้องเรียน พร้อมระบุระยะห่างจริงเป็นเมตร
   - **ปุ่มขยายแผนที่เต็มจอ (`⛶ ขยายเต็มจอ`)** รองรับการเลื่อนดู ซูมเข้า-ออก (Pinch-to-zoom) และปุ่มจัดกึ่งกลาง

4. **📸 ระบบภาพถ่ายหลักฐานตัวตน (Photo Evidence Verification)**
   - ถ่ายภาพสดจากกล้องขณะอยู่ในห้องเรียน
   - พรีวิวภาพถ่ายก่อนกดยืนยันส่งข้อมูลเข้าสู่ระบบ

5. **👤 การแก้ไขและจัดการรูปโปรไฟล์ (Profile Image Management)**
   - แตะที่รูปประจำตัวหรือกดปุ่มเพื่อเปลี่ยนรูปได้ทันที
   - รองรับทั้งการถ่ายรูปสดจากกล้อง หรือเลือกรูปจากคลังภาพ (Gallery)
   - ตัดรูปสัดส่วน 1:1 พอดีกับกรอบบัตรประจำตัว
   - มีตัวเลือกลบรูปเพื่อคืนค่าเป็นรูปเริ่มต้น

6. **🔔 ระบบแจ้งเตือน (Notifications System)**
   - รองรับการแจ้งเตือนเตือนเข้าเรียน (Class starting soon)
   - มีปุ่มทดสอบยิงการแจ้งเตือนในหน้าข้อมูลบัญชี (Profile)
   - ออกแบบระบบ Fallback ปลอดภัย รองรับทั้งบน Expo Go SDK 53+ และ Development Build

## 🛡️ กลไกการตรวจสอบ 3 ปัจจัย (3-Factor Verification)

การเช็กชื่อจะสำเร็จได้ ต้องผ่านการตรวจสอบครบทั้ง 3 ปัจจัย:

```
[ เวลาเรียนตรงเงื่อนไข ] + [ พิกัด GPS อยู่ในรัศมีห้องเรียน ] + [ ถ่ายภาพใบหน้าในห้องเรียน ]
                                      ⬇
                         ✓ บันทึกการเข้าเรียนสำเร็จ (มาเรียน)
```

| ปัจจัย | รายละเอียดการตรวจสอบ | เกณฑ์การผ่าน |
| :--- | :--- | :--- |
| **1. เวลา (Time)** | ตรวจสอบเวลาปัจจุบันเทียบกับเวลาคาบเรียน (`startTime` - `endTime`) | ต้องอยู่ในช่วงเวลาเรียนเท่านั้น (ไม่สามารถเช็กชื่อก่อนเวลาเริ่มได้) |
| **2. พิกัด (Location)** | คำนวณระยะห่างด้วยสูตร **Haversine Formula** ผ่าน GPS | ระยะห่างต้องน้อยกว่าหรือเท่ากับรัศมีที่อนุญาต (`distance <= allowedRadius`) |
| **3. ภาพถ่าย (Photo)** | ถ่ายภาพสดจากกล้องของอุปกรณ์ในห้องเรียน | มีภาพถ่ายหลักฐานส่งประกอบการเช็กชื่อ |

## 🗺️ ระบบแผนที่จริง (Real Interactive Map)

พัฒนาโดยใช้ **Leaflet.js + OpenStreetMap** ผ่าน `react-native-webview`:
- **ไม่ต้องใช้ Google Maps API Key** (ป้องกันปัญหาจอดำหรือโดนระงับโควตา API)
- ทำงานได้สม่ำเสมอทั้งบน Android, iOS และ Expo Go
- **ปุ่มควบคุมแผนที่**:
  - `🏫 ห้องเรียน`: บินมุมมองไปกึ่งกลางห้องเรียน
  - `👤 ตำแหน่งฉัน`: บินมุมมองไปตำแหน่งนักศึกษา
  - `⛶ จัดมุมมอง`: ซูมและปรับระยะให้มองเห็นทั้งสองจุดในหน้าจอเดียว
  - `⛶ ขยายเต็มจอ`: ขยายแผนที่เปิดเป็น Modal เต็มหน้าจอ เพื่อเลื่อนสำรวจพื้นที่ได้อย่างอิสระ

## 👥 บทบาทผู้ใช้งาน (User Roles)

### 1. 🎓 นักศึกษา (Student)
- **หน้าหลัก (Home)**: ดูตารางเรียนประจำวัน, สรุปสถานะการเข้าเรียน (มาเรียน, สาย, ขาด), และปุ่มเข้าเช็กชื่อสำหรับคาบที่เปิดอยู่
- **หน้าเช็กชื่อ (Attendance Verification)**:
  - ตรวจสอบเวลาเรียน
  - ตรวจสอบพิกัด GPS พร้อมดูตำแหน่งบนแผนที่จริง
  - ถ่ายรูปยืนยันตัวตน
  - ส่งข้อมูลและรับใบเสร็จยืนยันการเช็กชื่อ
- **หน้าประวัติ (History)**: ดูรายการเช็กชื่อย้อนหลังพร้อมรายละเอียดเวลา พิกัด ระยะห่าง และภาพถ่ายหลักฐาน
- **หน้าโปรไฟล์ (Profile)**: ดูบัตรประจำตัวนักศึกษา, แก้ไขรูปโปรไฟล์, และทดสอบระบบแจ้งเตือน

### 2. 👨‍🏫 อาจารย์ผู้สอน (Teacher)
- **หน้าหลัก (Home)**: สรุปภาพรวมการเปิดคาบเรียน, จำนวนนักศึกษาที่มาเช็กชื่อ, คาบเรียนที่กำลังเปิดรับอยู่
- **สร้างคาบเช็กชื่อ (Create Session)**:
  - เลือกรายวิชา, วันที่ (Date Picker), และเวลาเริ่ม-เลิกเรียนด้วยวงล้อนาฬิกาแบบเลื่อนวนลูป (Wheel Time Picker)
  - กำหนดห้องเรียนและรัศมีที่อนุญาต
  - ดึงพิกัด GPS ปัจจุบันของอาจารย์มาเป็นพิกัดห้องเรียนได้ในคลิกเดียว
  - พรีวิวพิกัดห้องเรียนและขอบเขตรัศมีบนแผนที่จริงได้ทันที
- **ตรวจสอบการเข้าเรียน (Attendance Records)**: ดูรายชื่อนักศึกษาที่มาเช็กชื่อแบบเรียลไทม์ พร้อมพิกัด ระยะห่าง และรูปถ่ายหลักฐาน
- **หน้าโปรไฟล์ (Profile)**: ดูบัตรประจำตัวอาจารย์, เปลี่ยนรูปโปรไฟล์, และทดสอบระบบแจ้งเตือน

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Framework**: [Expo](https://expo.dev/) (SDK 57) + [React Native](https://reactnative.dev/) (v0.86)
- **Routing**: [Expo Router](https://docs.expo.dev/router/introduction/) (File-based Routing with Typed Routes)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Map Engine**: [Leaflet.js](https://leafletjs.com/) + [OpenStreetMap](https://www.openstreetmap.org/) ผ่าน [`react-native-webview`](https://github.com/react-native-webview/react-native-webview)
- **Hardware & Device APIs**:
  - `expo-location`: อ่านค่าพิกัด GPS ความแม่นยำสูง
  - `expo-camera`: ใช้งานกล้องสำหรับถ่ายภาพหลักฐาน
  - `expo-image-picker`: เลือกและตัดรูปภาพสัดส่วน 1:1 สำหรับรูปโปรไฟล์
  - `expo-notifications`: ระบบการแจ้งเตือน
- **Local Storage**: `@react-native-async-storage/async-storage` สำหรับบันทึก Session และจำลองฐานข้อมูล Persistent

## 🚀 การติดตั้งและเริ่มใช้งาน (Getting Started)

### ความต้องการของระบบ (Prerequisites)
- [Node.js](https://nodejs.org/) (เวอร์ชัน 18 ขึ้นไป)
- แอปพลิเคชัน **Expo Go** บนมือถือ Android หรือ iOS (หรือ Android Studio Emulator / iOS Simulator)

### ขั้นตอนการติดตั้ง (Installation)

1. **ติดตั้ง Dependencies**:
   ```bash
   npm install
   ```

2. **เริ่มรันโปรเจกต์ด้วย Expo**:
   ```bash
   npm start
   # หรือ
   npx expo start
   ```

3. **เปิดแอปพลิเคชัน**:
   - สแกน QR Code บนเทอร์มินัลด้วยแอป **Expo Go** (สำหรับ Android) หรือแอปกล้อง (สำหรับ iOS)
   - หรือกดปุ่ม `a` ในเทอร์มินัลเพื่อเปิดบน Android Emulator
